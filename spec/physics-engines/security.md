# Physics integration security audit

This is the author/coordinator audit for Tranche B. It supplements automatic
review and numerical tests; it is not a live production acceptance receipt.

The service retains one authenticated owner-scoped queue and SkyPilot authority.
Declarative requests cannot supply Python, file paths, worker resources or a
native backend. Pure normalization and admission precede allocation. Stored
versioned execution contexts bind the normalized request, certified algorithm,
resource profile, native identity and immutable worker image. Older pinned
workers retain their original private input protocol without profile substitution.

Callbacks validate the stored result contract before commit: bounded member
count/bytes, uncompressed NPZ framing, NPY headers before loading, native finite
numeric dtypes/shapes, Unicode JSON metadata and exact summary agreement.
`allow_pickle=False` applies to artifacts and encrypted backup recovery. Owned
job credentials are excluded from native children and public output. Native
completion without a final callback cannot silently repeat computation.

The release verifier now requires contract version 2 and the exact 21-case
inventory, configured smoke owner, request/result/context digests, immutable
worker image, actual refreshed SkyPilot CPU allocation, native success and
cleanup. Downloaded HTTP result digests must equal the private probe's stored
artifact digests. A successful API callback alone is insufficient. Historical
version-1 receipts remain circuit-only and cannot qualify physics promotion.
The standalone GitHub gate remains stdlib-only; PR CI receives no deployment or
cluster credentials.

Independent acceptance math includes phase/time units, damping and density
physicality, propagator representation, eigenpairs and charge-basis matrix
elements, exact exported numeric handoff, and the original frozen JoSIM waveform
plus SI units and SFQ integrals. MC relaxation is derived from the pinned
SeedSequence/PCG64 jump thresholds and absorbing-ground-state equation, not
repeatability alone.

The scoped peer audit found four concrete gaps before publication: JoSIM's full
native version identity, MC dynamics, consistent receipt-owner substitution,
and failure after an open acknowledgement or final receipt write. All have
source corrections and regression coverage. Post-open failure attempts to
restore the owning hold without cancelling accepted jobs; failed version and
deployment receipts remain failed. An unverified hold recovery stays explicitly
unverified and requires operator recovery. Process/host loss still requires the
existing operational reconciliation; no filesystem/remote-command sequence is
claimed to be a distributed atomic transaction.

Remaining operational gate: exact merged-source CI, real fresh encrypted
backup/readback and recovery evidence, candidate image promotion, restricted
smoke through real SkyPilot, full-matrix math/native cleanup and a durable
verified deployment receipt. Any unresolved stage retains its gate. Existing
credentials, recovery keys, backup controls and unrelated workloads are unchanged.
