# Execution decisions

Status: TASK-002 execution decisions recorded on 2026-10-13 following TASK-001: 24 capability tests and five existing engine tests passed. These decisions stay within the approved design. No additional simulator or dependency is selected.

| Open item | Execution decision | Evidence / verification |
| --- | --- | --- |
| OR-001 | Use installed Cirq 1.7.0 importer and qsimcirq 0.22.1 for the supported Google qsim subset. Retain Clifft 0.11.0 native legacy paths. Classical controls remain unsupported; never remove them or route to another engine. | Capability report and executable tests; parsing alone does not establish support. |
| OR-002 | Use QASM3 importer-supported sized float[32]/float[64]/angle[32]/angle[64] inputs with finite numeric bindings. Reject extra/missing names and bool/string/null/nonfinite values. Normalize accepted numbers to finite Python floats, normalize signed zero to 0.0, sort binding names. Numeric evaluation uses the installed Cirq resolver with finite Python double values, not a claim of width-specific IEEE arithmetic. New bindings affect only new request identity; legacy payload bytes stay unchanged. Reject values not representable as finite floats. | Bound reference circuits, numeric-equivalence/conflict tests and legacy frozen hashes. |
| OR-003 | Accept the approved qasm-samples/1 final-memory schema: declaration-order registers, ascending bit indices, zero-initialized unwritten bits, last write wins. Reject sampling without measurements. Keep 256 count entries ordered by descending count then lexical key, first 20 shots as preview, complete memory in NPZ. | Deterministic asymmetric fixtures; repeated writes and unused bits. |
| OR-004 | Proposed custom gate limit: 65,536 expanded primitive operations, nesting depth 32. Count the native compact CircuitOperation graph before decomposition; reject over-budget graphs. Preflight register sizes through existing lexer tokens before parser allocation; preserve existing qubit/input bounds and limit shots × classical bits to 1,000,000. Exact allowlisted include names are required. | Compact doubling-gate probes establish count without expansion; executor must test at/over limits and any repetition semantics before enabling custom gates. These are service policy limits, not claims about engine capacity. |
| OR-005 | Keep incremental_samples=false. Preserve resumable progress/final events. | Existing SSE regression tests; no sample chunk contract is introduced. |
| OR-006 | For small analytic probability fixtures use absolute tolerance 1e-6 for qsim single precision, 1e-10 for Clifft where its existing exact fixtures support this. Use deterministic measurement circuits for correctness; Bell frequency smoke uses 4,096 shots and an absolute 0.05 bound around 0.5, declared before execution. Do not require equal cross-engine seeded sequences. | Fixture-specific explicit assertions; failures require investigation, not relaxed tolerances after observing results. |
| OR-007 | Before release compare median unchanged-unitary worker runtime across 10 alternating baseline/candidate executions of the same small circuits and engine. Accept at most max(20% of baseline median, 0.1 seconds) added median runtime. Record environment and raw timings; startup and native execution timings remain distinct. | Release validation, no new latency SLO or active job deadline. |

Material deviations from the approved design return to owner review. Routine details above resolve open implementation choices within that design. Each feature is enabled only after its own probes, safety bounds and tests pass. If QASM3/binding/custom-gate safety cannot be demonstrated, defer that feature while completing independently supported sampling.
